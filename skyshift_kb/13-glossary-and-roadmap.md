**עודכן לאחרונה:** 30 באוקטובר 2026

## חלק א: מילון מונחים

| מונח | משמעות |
|---|---|
| **SkyShift** | המיזם, וגם השם הטכני של הפלטפורמה שלו |
| **עולים לאוויר** | השם העסקי העברי של SkyShift |
| **משתתף (User)** | אדם שנרשם לפלטפורמת SkyShift |
| **מנהל (Manager)** | חבר בצוות התפעול של SkyShift, עם הרשאות ניהול |
| **חודש ניסוי** | תקופת הקצאת הרכב של חודש: מרגע הבחירה ועד בדיוק חודש אחר כך, כולל שני הקצוות |
| **הקצאת רכב** | הרישום שמקשר משתתף לרכב לחודש ניסוי |
| **ממוצע נסיעות יומי** | המספר השלם שהמשתתף מצהיר עליו בהרשמה |
| **יעד חודשי (נסיעות צפויות בחודש)** | ממוצע נסיעות יומי × 30 |
| **טיסה שהושלמה** | טיסה שהפלטפורמה קיבלה בתוך חודש הניסוי הפעיל |
| **אחוז השלמה** | טיסות שהושלמו × 100 ÷ יעד חודשי, מעוגל כלפי מטה |
| **סף הזכאות** | 80% מהיעד החודשי |
| **מחזור הגרלה** | תקופה שמתפרסמת מראש, ובסופה נערכת הגרלה בין המשתתפים הזכאים |
| **משקיף בלתי תלוי** | אדם שאינו עובד SkyShift ומפקח על ההגרלה |
| **רכב ניסיוני / רכב ניסיוני אישי** | רכב בצי שמיועד לשימוש אישי בניסוי, ומתוכו מתוכנן להגיע פרס ההגרלה |
| **קטלוג** | רשימת 22 דגמי הרכב שמהם נוצרים רכבי הצי |
| **צי** | הרכבים בפועל שהמשתתפים יכולים לבחור |
| **מאומת (מפרט יצרן)** | ערך שנלקח ממסמך רשמי של היצרן |
| **להמחשה** | נתון לדוגמה של SkyShift, ולא מפרט יצרן |
| **השראה חזותית** | דגם קטלוג שזהותו המדויקת לא אומתה |
| **סטטוסים של רכב** | פנוי, בשימוש, תחזוקה, לא זמין, הוצא משירות |
| **SkyCar** | קונספט הרכב הדו-מצבי של SkyShift, לכביש ולאוויר |
| **SkyCar Five** | קונספט הדגל: 4 נוסעים ועוד טייס בטיחות |
| **SkyCar Two** | קונספט קל יותר: נוסע אחד ועוד טייס בטיחות |
| **מצב כביש** | ה-SkyCar פועל כמכונית חשמלית |
| **מצב אוויר** | ה-SkyCar פועל ככלי טיס eVTOL |
| **SkyPad** | אתר ייעודי ומאושר להמראה, לנחיתה, להמרה ולטעינה |
| **המרה** | מעבר בין מצב כביש למצב אוויר, רק ב-SkyPad |
| **טייס בטיחות** | טייס מיומן ומוסמך של SkyShift שמבצע כל טיסה בשלב הפיילוט |
| **מרכז הפיקוח על הטיסות** | המרכז של SkyShift שמנטר כל טיסה בזמן אמת |
| **eVTOL** | כלי טיס חשמלי בהמראה ונחיתה אנכית |
| **Powered-lift** | הקטגוריה של ה-FAA שאליה שייכים רוב כלי הטיס מסוג eVTOL |

| **הקטגוריה המשופרת (Enhanced)** | הקטגוריה המחמירה יותר של SC-VTOL, לפעילות מעל אזורים צפופים או להסעת נוסעים מסחרית |
| **10⁻⁹ לשעת טיסה** | אחד למיליארד: יעד ההסתברות המרבי למצבי כשל קטסטרופליים בקטגוריה המשופרת |
| **SSF** | מסגרת הבטיחות של SkyShift |
| **גידור גיאוגרפי (Geofencing)** | פונקציה בבקרת הטיסה שמונעת מכלי הטיס לצאת מהאזור המאושר שלו |
| **מצנח חילוץ בליסטי** | מצנח שיכול להוריד את כל הרכב במקרה חירום קיצוני |
| **CAAI** | רשות התעופה האזרחית בישראל |
| **INDI** | המיזם הלאומי לרחפנים בישראל (SkyShift אינו חלק ממנו) |
| **שלב ההדגמה** | השלב הנוכחי: הפלטפורמה פעילה, אבל אין טיסות אמיתיות ואין הגרלה פעילה |

## חלק ב: מפת דרכים

> כל התאריכים שאחרי אוקטובר 2026 הם **תוכניות**, לא התחייבויות. כל שלב שקשור לטיסות תלוי באישורים רגולטוריים ובעמידה במסגרת הבטיחות של SkyShift.

### שלב 1: יסודות (הושלם)

**מרץ 2025 – יוני 2026**
- הקמת SkyShift.
- שלב המחקר: סקר משתתפים, ראיונות, סקירת רגולציה.
- הגדרת קונספט ה-SkyCar.
- הגרסה הראשונה של מסגרת הבטיחות של SkyShift.
- אישור כללי תוכנית הניסוי.

### שלב 2: פלטפורמת ההדגמה (נוכחי)

**ספטמבר 2026 – תחילת 2027**
- פלטפורמת SkyShift: אזור משתתפים ואזור מנהלים. *(הושלם.)*
- קטלוג של 22 דגמי רכב עם תוויות דיוק. *(הושלם.)*
- תמיכה ב-PostgreSQL ופרסום ציבורי. *(הושלם.)*
- **בוט העוזר של SkyShift**, שעונה על שאלות ממאגר הידע הזה. *(בפיתוח.)*
- החזרה אוטומטית של רכבים למאגר הפנוי בסוף ניסוי. *(מתוכנן.)*
- איפוס סיסמה ועריכת פרופיל. *(מתוכנן.)*
- היסטוריית טיסות אישית למשתתפים. *(מתוכנן.)*

### שלב 3: הנדסה ואישורים (מתוכנן)

**2027**
- תכנון מפורט של ה-SkyCar Five.
- בדיקות קרקע של ההנעה, הסוללות ומערכות בקרת הטיסה.
- דיונים עם רשויות התעופה הרלוונטיות על בסיס ההסמכה ועל הבסיס התפעולי.
- בחירת אתרים ל-SkyPads הראשונים.
- תוכנית הכשרה לטייסי הבטיחות.

### שלב 4: פיילוט סגור (מתוכנן)

**בכפוף לאישורים**
- מספר קטן של SkyCars ו-SkyPads באזור מוגדר במרכז הארץ.
- קבוצה מוגבלת של משתתפים.
- אימות טיסות אוטומטי מנתוני הרכב.
- הזמנת טיסות ותיאום SkyPads בפלטפורמה.
- מחזור ההגרלה הראשון, לפי תקנון ההגרלה המפורסם.

### שלב 5: למידה והרחבה (חזון)

- פרסום תוצאות מצרפיות ואנונימיות של הפיילוט.
- הרחבה הדרגתית של רשת ה-SkyPads והנתיבים.
- בחינה ארוכת טווח של האפשרות לפעילות אוטונומית יותר, בכפוף לאישור רגולטורי נפרד.

## חלק ג: מה לא ישתנה

מה שלא תביא מפת הדרכים, שלושה דברים נשארים קבועים:

1. **אין טיסה בלי אישור בטיחות ורגולציה מלא.**
2. **הצהרה ברורה על המצב:** הדגמה, המחשה ויעד תכנון תמיד מסומנים ככאלה.
3. **אותם כללים לכולם**, שמחושבים על ידי המערכת ומתפרסמים מראש.
